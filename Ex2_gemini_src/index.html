Firmware Framework

Bare-Metal MCU & Device Driver Framework

Khung điều khiển bare-metal tái sử dụng cho STM32L432KC lập trình trực tiếp mức thanh ghi (register-level) và định nghĩa CMSIS, cung cấp lớp trừu tượng phần cứng không phụ thuộc STM32 HAL.

  • Lập trình trình điều khiển ngoại vi UART/USART/LPUART, I2C, SPI, CAN, SAI, USB, TIM, ADC/DAC, DMA ngắt và quản lý năng lượng thấp.
  • Xây dựng máy trạng thái hướng sự kiện (event-driven FSM) cho cảm biến IMU, ToF, xác thực vân tay/RFID, màn hình OLED/TFT.
STM32L4 Bare-Metal C CMSIS CAN Bus Register-Level
IoT & Edge Gateway

Raspberry Pi Edge Gateway & IoT Platform

Nền tảng biên IoT xây dựng trên Raspberry Pi 4 kết hợp mạng nốt cảm biến từ xa ESP8266 thu thập dữ liệu DHT11, IMU, MQ-gas qua GPIO, I2C/SPI.

  • Truyền dữ liệu an toàn qua Wi-Fi bằng MQTT qua TLS với vòng lặp sự kiện non-blocking và xử lý kết nối.
  • Cổng gateway chạy Mosquitto broker và dịch vụ Python lưu trữ dữ liệu vào SQLite, phát hiện bất thường và cung cấp RESTful API bằng FastAPI.
Raspberry Pi ESP8266 FastAPI MQTT/TLS SQLite
